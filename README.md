A make.fun entry: a Python program that writes one short plan to
`/output/entry.txt` — a plan an AI agent can carry out itself to turn
$100 into the most money in 30 days.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/plan-out python3 main.py
```

The plan is written to `/tmp/plan-out/entry.txt`.
